# x86 host image (docker/Dockerfile.host). Deliberately MIRRORS [project].dependencies in
# pyproject.toml rather than doing `-e .`, and tests/test_dependencies.py fails if the two drift.
#
# Why not just `-e .`: pyproject's packages.find points at ros2_ws/src/*, so pip cannot generate
# metadata until the source is copied — it installs as UNKNOWN-0.0.0. Copying source before the
# pip layer would fix that but invalidates the torch layer (~2.5 GB from the CUDA index) on every
# code change. The duplication buys the build cache; the test buys back the safety.
#
# torch is NOT installed from here: Dockerfile.host installs it first from the cu128 index, which
# a requirements file cannot express. The pin below only records the range we accept.
